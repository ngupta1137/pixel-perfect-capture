## 🚀 Golden Production Rules for Claude (Learned from Scenario 1)

Every script generated by Claude MUST include these battle-tested production improvements:

### 1. Pacing & Dynamic Speed-Up (`GAP_SPEED = 3`):
- **Trim Lead-In Silence:** Automatically drop dead air before the first spoken sentence:
  ```javascript
  const firstCue = timeline[0].startMs / 1000;
  if (firstCue - 0.8 > 1.5) cuts.push({ startMs: 0, endMs: (firstCue - 0.8) * 1000 });
  ```
- **3× Acceleration on Un-narrated Gaps:** Speed up stretches where the mouse is gliding, typing, or navigating without spoken narration by 3× using FFmpeg's `split` + `trim` + `setpts` + `concat` filter graph:
  ```javascript
  const SPEED = Number(process.env.GAP_SPEED || 3);
  pieces.push({ a, b, speed: !inWin(m) && b - a > 3 ? SPEED : 1 });
  ```
- **Cut Idle Server Waits:** Any database or submission wait exceeding 4 seconds is added to `cuts` and automatically dropped from the video track.

### 2. Audio & Environment Configuration:
- **Auto-load `.env`:** Never require manual PowerShell `$env:` exports. Parse `.env` at script startup.
- **Auto-discover FFmpeg / ffprobe:** Prepend `path.join(process.env.LOCALAPPDATA || "", "Microsoft", "WinGet", "Links")` to `process.env.PATH`.
- **Cloned ElevenLabs Voice:** Always use active custom voice `RfKtG66Co2EredaKMj6o`.
- **Audio Caching (`REUSE_AUDIO=1`):** Check if `audio/tts.json` already exists before calling ElevenLabs to save API credits and speed up iteration.

### 3. Visual Spotlight Directing:
- **Smooth Cursor Gliding:** Use cubic easing curves (`glideTo(x, y)`).
- **Pulsing Green Spotlight Ring:** Inject `#vty-ring` (`border: 3px solid #22c55e`, `box-shadow: 0 0 22px 6px rgba(34,197,94,.8)`).
- **Element Zoom:** Scale the active target element to `scale(1.05)` during explanation.
- **Teleprompter Subtitles:** Display active narration inside `#vty-sub` centered at bottom.

### 4. Resilient Navigation:
- Never assume an asynchronous transition happened instantly; use race conditions or explicit click fallbacks (e.g. if a tab does not switch automatically after submission, explicitly click the tab locator).

### 5. Strict On-Screen Grounding & Visual Truthfulness:
- **Zero Hallucination in Voiceover:** Every word spoken in the voiceover and shown in subtitles MUST describe elements, numbers, tables, and buttons that are visibly rendered on the screen.
- **Never reference phantom UI:** If a table shows `When`, `Actor`, `Action`, `Target`, `Detail`, do NOT speak of cryptographic hashes or imaginary columns.
- **Inspect actual code before writing script:** Look directly at the React components (`src/routes/...`) to ensure labels, selectors, and state matches reality.

## Troubleshooting & Audio Configuration Tips

### 1. Zero-Dependency Mode (Live Chrome Voice via Web Speech API)
When running scripts like `node scenario-1-voice-demo.mjs`:
- Chrome has built-in speech synthesis (`SpeechSynthesisUtterance`).
- It uses your installed Windows voices (`Microsoft David Desktop` or `Microsoft Zira Desktop`) and plays in real time through your computer speakers.
- **Recording with Audio:** Use Windows Game Bar (`Win + Alt + R`) or OBS Studio while the script runs to capture both video and speaker sound simultaneously.

### 2. High-Fidelity Pre-Rendered Audio Mode (`make-scenario-1-video.mjs`)
If you want automated MP4 videos with baked-in audio using `python scenario-1-tts.py` and `ffmpeg`:
- **Free High-Quality Edge-TTS (No API Key Required):**
  ```powershell
  pip install edge-tts
  $env:TTS_ENGINE="edge"
  node make-scenario-1-video.mjs
  ```
- **ElevenLabs AI Cloned Voice:**
  ```powershell
  $env:ELEVENLABS_API_KEY="your_api_key_here"
  $env:ELEVEN_VOICE_ID="RfKtG66Co2EredaKMj6o"
  $env:TTS_ENGINE="elevenlabs"
  node make-scenario-1-video.mjs
  ```
- **FFmpeg & FFprobe Setup:**
  Download FFmpeg from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (e.g. `ffmpeg-release-essentials.zip`), extract it to `C:\ffmpeg`, and add `C:\ffmpeg\bin` to your Windows PATH, or install via winget:
  ```powershell
  winget install Gyan.FFmpeg
  ```
